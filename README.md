# Prototype Website Portfolio

A collection of clean, mobile-responsive HTML/CSS website prototypes, one new business category added each weekday by an automated routine.

Each prototype is a **single self-contained HTML file** (no build step, no external dependencies) — open it directly in a browser or via GitHub Pages.
